# What the scraper image installs, named rather than filtered.
#
# Subtracting a few lines from requirements.txt left opencv-python, yt-dlp, numpy and
# Pillow in an image that opens none of them — over 100 MB for nothing. This list was
# derived from what backend/archive and backend/storage actually import.
#
# Deliberately absent: flask and psycopg (the scraper is not the API).
#
# The old reason for leaving playwright out was that the four brands wanting a browser
# were the four producing nothing, so a browser bought us nothing. That is no longer
# true (2026-09-20): Vivienne Westwood and Van Cleef produce over T1 below, The Outnet
# is Shopify, and Gentle Monster produces with a browser. The lane now has exactly one
# brand behind it, and the question is whether one brand justifies a Chromium in an
# always-on worker — see Dockerfile.scraper.
#
# curl_cffi is here for the opposite reason. It is browser-grade *access* — libcurl over
# BoringSSL with real Chrome cipher ordering — without a browser: a ~5 MB wheel and no
# Chromium, so the small image keeps its shape while the brands that refuse our Python
# TLS fingerprint become reachable.

httpx>=0.27
curl_cffi>=0.7
# Pinned to the base image's tag in Dockerfile.scraper: the browsers it ships are built
# for exactly this version, and a mismatch fails at launch rather than at install.
playwright==1.40.0
pydantic>=2.5
PyYAML>=6.0
beautifulsoup4>=4.12.0
lxml>=4.9.0
boto3>=1.34
anthropic>=0.25.0
python-dotenv>=1.0.0
